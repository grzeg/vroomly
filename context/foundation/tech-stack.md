## Why this stack

Vroomly is a web-app for individual car owners tracking fuel costs and maintenance. The 3-week timeline and small-team profile favor a battle-tested, opinionated starter. 10x Astro Starter delivers auth, database, and edge deployment out of the box via Astro + React + Supabase + Cloudflare, all with explicit TypeScript contracts and strong conventions. This stack is the recommended default for web products in JavaScript and carries first-class bootstrapper support, meaning scaffolding is well-tested and you'll ship quickly.
